☁️ Đồng Bộ Thời Gian Thực Nhiều Thiết Bị

Kết nối với Google Firebase Realtime Database (miễn phí 100%) để khi bạn điểm danh hoặc thêm/sửa võ sinh trên máy này, mọi điện thoại và máy tính khác mở trang web đều tự động cập nhật ngay lập tức.

💡 Mẹo: Bạn cũng có thể dán trực tiếp link này vào biến DEFAULT_CLOUD_DB_URL ở dòng đầu file app.js để mọi người mở web lên là tự động đồng bộ luôn mà không cần nhập lại.
Hướng dẫn tạo nhanh trong 1 phút (Miễn phí):
  1. Vào console.firebase.google.com → Bấm Create a project.
  2. Ở menu trái, chọn Build → Realtime Database → Create Database.
  3. Chọn chế độ Start in test mode (hoặc bật read/write: true trong tab Rules).
  4. Copy đường link https://...firebasedatabase.app dán vào ô bên trên và bấm Kết nối & Đồng bộ.
